文本、排版、状态与媒体类展示组件：多为纯渲染、无表单语义，按声明的 props 与表达式求值结果呈现内容（Segmented 为录入型控件，Form 集成见该小节说明）。

### Text

普通文本渲染，支持语义类型与修饰。

| prop | 类型 | 说明 |
| --- | --- | --- |
| `text` | string | 文本内容（可含表达式）；也可用 children |
| `type` | `default`（默认）\| `secondary` \| `success` \| `warning` \| `danger` | 语义类型（颜色） |
| `size` | `middle`（默认）\| `small` \| `large` | 字号：small 12px / middle 继承上下文 / large 18px |
| `strong` | boolean | 加粗 |
| `delete` | boolean | 删除线 |
| `underline` | boolean | 下划线 |
| `italic` | boolean | 斜体 |

```yaml
- type: Text
  props: { text: 共 ${state.count} 条记录, type: secondary }
- type: Text
  props: { text: 重要提示, type: danger, strong: true }
```

### Typography

排版样式文本：按 `variant` 渲染对应语义标签与排版样式。

| prop | 类型 | 缺省 | 说明 |
| --- | --- | --- | --- |
| `variant` | `h1` \| `h2` \| `h3` \| `h4` \| `p` \| `blockquote` \| `list` \| `inline-code` \| `lead` \| `muted` \| `small` | `p` | 排版变体 |
| `text` | string | — | 文本内容（可含表达式） |

```yaml
- type: Typography
  props: { variant: h2, text: 章节标题 }
- type: Typography
  props: { variant: muted, text: 辅助说明文字 }
```

### Avatar

头像：图片加载失败或未提供 `src` 时显示 `fallback` 占位（如首字母）。

| prop | 类型 | 缺省 | 说明 |
| --- | --- | --- | --- |
| `src` | string | — | 图片地址 |
| `alt` | string | — | 图片替代文本 |
| `fallback` | string | — | 加载失败或缺省时的占位文本（如首字母） |

```yaml
- type: Avatar
  props: { src: ${data.user.avatar}, fallback: 张 }
```

### Empty

空状态：标题 + 说明，children 为可选操作区（DSL 子树）。

| prop | 类型 | 缺省 | 说明 |
| --- | --- | --- | --- |
| `title` | string | — | 空状态标题 |
| `description` | string | — | 辅助说明文案 |
| children | DslNode[] | — | 操作区（DSL 子树，经 Renderer children 机制渲染） |

```yaml
- type: Empty
  props: { title: 暂无数据, description: 创建第一条记录开始使用 }
  children:
    - type: Button
      props: { text: 新建, variant: primary }
```

### Icon

lucide 图标。`name` 取自内置常用图标白名单（`ICONS` 导出，kebab-case 键；同时接受 PascalCase / camelCase，自动归一）；未知名渲染占位图标并标 `data-unknown`，不抛错。白名单为静态导入（可 tree-shake），新增图标在 `packages/ui/src/components/components/Icon/index.tsx` 补充一行导入 + 一行映射。

| prop | 类型 | 缺省 | 说明 |
| --- | --- | --- | --- |
| `name` | string | — | 图标名（如 `check-circle` / `CheckCircle`） |
| `size` | `sm` \| `default` \| `lg` \| number | `default` | 尺寸（sm 16 / default 20 / lg 24，数字直接作 px） |
| `color` | string | — | 颜色（CSS 颜色值，缺省 currentColor 跟随文本色） |
| `strokeWidth` | number | `2` | 描边宽度 |

```yaml
- type: Flex
  props: { gap: 8 }
  children:
    - type: Icon
      props: { name: check-circle, color: green }
    - type: Icon
      props: { name: arrow-right, size: lg }
```

### AspectRatio

固定宽高比容器，children 内容按比例约束。

| prop | 类型 | 缺省 | 说明 |
| --- | --- | --- | --- |
| `ratio` | number \| string | `1` | 宽高比（如 `16/9`，数字或 `'16/9'` 字符串） |
| children | DslNode[] | — | 内容（DSL 子树，按比例约束渲染） |

```yaml
- type: AspectRatio
  props: { ratio: 16/9 }
  children:
    - type: Text
      props: { text: 16:9 区域 }
```

### Carousel

轮播（embla-carousel）：items 支持图片对象或 DSL 子树；`autoplay` 以定时器驱动 scrollNext（`loop` 时回绕，否则停在末页）。

| prop | 类型 | 缺省 | 说明 |
| --- | --- | --- | --- |
| `items` | `Array<{ src: string, alt?: string } \| DslNode>` | `[]` | 轮播项：图片对象数组或 DSL 子树数组（经 renderChildren 渲染） |
| `loop` | boolean | `false` | 循环滚动 |
| `autoplay` | boolean \| number | — | 自动播放：`true` 用默认间隔（3000ms），数字为间隔毫秒数 |

```yaml
- type: Carousel
  props:
    loop: true
    autoplay: 3000
    items:
      - { src: /banners/a.png, alt: 活动 A }
      - { src: /banners/b.png, alt: 活动 B }
```

### Item

三段式列表项：media / title+description / actions。

| prop | 类型 | 缺省 | 说明 |
| --- | --- | --- | --- |
| `title` | string | — | 标题 |
| `description` | string | — | 描述文本 |
| `media` | DslNode \| DslNode[] | — | 媒体区（DSL 子树，经 renderChildren 渲染） |
| `actions` | DslNode[] | — | 操作区（DSL 子树，经 renderChildren 渲染） |

```yaml
- type: Item
  props:
    title: 季度报告.pdf
    description: 2.4 MB · 昨天更新
    media:
      type: Avatar
      props: { fallback: 文 }
    actions:
      - type: Button
        props: { text: 下载, variant: link }
```

### List

纵向行式列表：每项为「左头像（图片地址或占位文本）— 中标题+描述 — 右附加文本」；items 为空时渲染「暂无数据」空态。

| prop | 类型 | 缺省 | 说明 |
| --- | --- | --- | --- |
| `items` | `Array<{ key?, title, description?, avatar?, extra? }>` | `[]` | 列表数据（可含表达式解析后的数组）；`avatar` 为图片地址（http(s): / data: / 路径）或占位文本 |
| `split` | boolean | `true` | 行间分隔线 |
| `bordered` | boolean | — | 外边框 |

```yaml
- type: List
  props:
    bordered: true
    items:
      - { title: 季度报告.pdf, description: 2.4 MB · 昨天更新, avatar: 文, extra: 已归档 }
      - { title: 设计稿.png, avatar: /files/preview.png, extra: 待评审 }
```

### Tree

树形展示：chevron 展开 + 缩进 + 可选勾选框。展开 / 选中 / 勾选均支持受控（对应 props 传入即受控）与非受控（`default*Keys` 初始化内部状态）；勾选为独立勾选（父子不联动），父节点按子孙勾选状态显示半选。

| prop | 类型 | 缺省 | 说明 |
| --- | --- | --- | --- |
| `treeData` | `Array<{ key, title, children?, disabled? }>` | `[]` | 树数据（可含表达式解析后的数组） |
| `defaultExpandedKeys` | string[] | — | 非受控初始展开 keys |
| `expandedKeys` | string[] | — | 受控展开 keys |
| `selectedKeys` | string[] | — | 受控选中 keys |
| `defaultSelectedKeys` | string[] | — | 非受控初始选中 keys |
| `checkable` | boolean | — | 节点前显示勾选框 |
| `checkedKeys` | string[] | — | 受控勾选 keys |
| `defaultCheckedKeys` | string[] | — | 非受控初始勾选 keys |
| `disabled` | boolean | — | 整树禁用 |
| 事件 `onSelect` | — | — | 选中节点时触发，`${event}` 为选中 keys 数组 |
| 事件 `onExpand` | — | — | 展开变化时触发，`${event}` 为展开 keys 数组 |
| 事件 `onCheck` | — | — | 勾选变化时触发，`${event}` 为勾选 keys 数组 |

```yaml
- type: Tree
  props:
    checkable: true
    defaultExpandedKeys: [rd]
    treeData:
      - key: rd
        title: 研发中心
        children:
          - { key: rd-fe, title: 前端组 }
          - { key: rd-be, title: 后端组 }
      - { key: design, title: 设计中心 }
  events:
    onSelect:
      action: setState
      params:
        selected: ${event}
```

### Descriptions

标签—值对栅格；`bordered` 时以边框栅格呈现。

| prop | 类型 | 缺省 | 说明 |
| --- | --- | --- | --- |
| `title` | string | — | 标题 |
| `items` | `Array<{ label, value: string \| number }>` | `[]` | 描述项列表（可含表达式解析后的数组） |
| `column` | number | `3` | 每行列数 |
| `bordered` | boolean | — | 带边框样式 |

```yaml
- type: Descriptions
  props:
    title: 订单详情
    bordered: true
    column: 2
    items:
      - { label: 订单号, value: ${data.order.id} }
      - { label: 金额, value: ${data.order.amount} }
      - { label: 状态, value: 已支付 }
```

### Timeline

竖向时间轴：节点圆点（`color` 覆盖颜色，`icon` 用 [Icon 白名单](#icon)图标替代圆点）+ 内容 + 可选时间；`pending` 在末尾追加「进行中」节点。

| prop | 类型 | 缺省 | 说明 |
| --- | --- | --- | --- |
| `items` | `Array<{ content, time?, color?, icon? }>` | `[]` | 节点列表（可含表达式解析后的数组） |
| `pending` | boolean \| string | — | 末尾追加「进行中」节点：`true` 用默认文案，字符串为自定义文案 |

```yaml
- type: Timeline
  props:
    pending: 等待审核
    items:
      - { content: 创建订单, time: '2026-09-18 10:00' }
      - { content: 支付成功, time: '2026-09-18 10:05', color: green, icon: check-circle }
```

### Image

图片：加载失败或未提供 `src` 时渲染 `fallback`（缺省为图标 + 灰色占位块）；`preview` 缺省开启，点击经弹层放大查看（居中大图，可关闭）。

| prop | 类型 | 缺省 | 说明 |
| --- | --- | --- | --- |
| `src` | string | — | 图片地址 |
| `alt` | string | — | 替代文本 |
| `width` | number \| string | — | 宽度（px 数字或 CSS 长度） |
| `height` | number \| string | — | 高度（px 数字或 CSS 长度） |
| `fallback` | string | — | 加载失败时显示的内容；缺省为图标 + 灰色占位块 |
| `preview` | boolean | `true` | 点击弹层放大预览 |

```yaml
- type: Image
  props: { src: /banners/cover.png, alt: 封面, width: 200 }
```

### QRCode

二维码：由编码内容生成内联 SVG；`value` 为空时渲染占位块。

| prop | 类型 | 缺省 | 说明 |
| --- | --- | --- | --- |
| `value` | string | — | 编码内容；为空时渲染占位块 |
| `size` | number | `128` | 尺寸（px） |
| `color` | string | — | 码体颜色（hex，可带透明度位，如 `#000000` / `#00000080`；非法值回退默认黑色） |
| `bgColor` | string | — | 背景色（同 `color` 格式；非法值回退默认白色） |
| `bordered` | boolean | — | 带边框与内边距 |

```yaml
- type: QRCode
  props: { value: 'https://example.com/invite/abc', size: 160, bordered: true }
```

### Segmented

药丸式分段选择器（选中项高亮）。录入型控件：在 Form 内声明 `name` 即自动成为表单项（`label` / `rules` 语义同[表单组件](./form.md)的录入控件）。

| prop | 类型 | 缺省 | 说明 |
| --- | --- | --- | --- |
| `name` | string | — | 字段名；在 Form 内声明 name 即自动成为表单项 |
| `label` | string | — | 表单项标签 |
| `rules` | FieldRule[] | — | 校验规则（见[校验规则（FieldRule）](./form.md#校验规则fieldrule)） |
| `options` | `Array<{ label, value, icon?, disabled? }>`（value: string \| number） | `[]` | 选项列表；`icon` 为 [Icon 白名单](#icon)图标名 |
| `value` | string \| number | — | 受控值（独立渲染时生效）；Form 内作为字段初始值 |
| `disabled` | boolean | — | 整体禁用 |
| 事件 `onChange` | — | — | 选中变化时触发，`${event}` 为选中项的 value |

```yaml
- type: Segmented
  props:
    name: viewMode
    options:
      - { label: 列表, value: list, icon: list }
      - { label: 卡片, value: card, icon: layout-grid }
  events:
    onChange:
      action: setState
      params:
        viewMode: ${event}
```
