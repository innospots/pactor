## 模块全景

**基础协议层**（零 React 依赖）

- [pactor-core](/packages/core/)：DSL 核心协议类型与通用 Registry
- [pactor-schema](/packages/schema/)：JSON Schema 与 Ajv 结构化校验
- [pactor-expression](/packages/expression/)：受控表达式引擎（无 eval，无全局访问）

**运行时层**

- [pactor-runtime](/packages/runtime/)：Runtime 引擎（上下文 / 状态 / 数据源 / 动作 / 生命周期）+ React Renderer

**能力层**

- [pactor-ui-antd](/packages/ui-antd/)：antd UI kit（V1 基础组件 / Overlay 交互 / 应用外壳布局 + `antdUiKit` 预设）
- [pactor-ui-radix](/packages/ui-radix/)：Radix UI kit（与 antd 版契约一致 + `radixUiKit` 预设 + 合并样式表）
- [pactor-permission](/packages/permission/)：权限 Store 与四层守卫
- [pactor-resource](/packages/resource/)：DSL 资源加载、缓存与版本控制
- [pactor-router](/packages/router/)：菜单注册、动态路由与导航桥接

**集成层**

- [pactor-app](/packages/app/)：一站式组合层——`createPactorApplication({ appId, api }).mount('#root')`

## 设计原则

- **DSL 是协议，不只是配置文件** —— 描述应用、页面、状态、数据源、事件、权限与交互。
- **动态 DSL，静态能力** —— 服务端动态下发 DSL，可调用的能力由前端 Runtime 的 Registry 明确定义，禁止注入任意 JavaScript。
- **Runtime 是框架核心** —— DSL → Parser/Validator → Runtime Context → Registry → Renderer。
- **复杂业务允许逃逸到 React/TypeScript** —— DSL 不追求表达所有业务逻辑。
