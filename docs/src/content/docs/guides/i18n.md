---
title: 国际化
description: Pactor 应用的国际化（i18n）配置与使用指南
---

Pactor 提供轻量级的国际化支持，覆盖应用外壳、页面 DSL 与内置组件文案。本指南介绍如何配置和使用 i18n。

## 快速开始

### 静态配置

在 `createPactorApplication` 中传入 `locale` 与 `messages`：

```tsx
import { createPactorApplication } from '@pactor-app/app';

createPactorApplication({
  appId: 'my-app',
  locale: 'en-US',
  messages: {
    'menu.home': 'Home',
    'menu.customers': 'Customers',
  },
}).mount('#root');
```

### 服务端下发

bootstrap 资源可携带 `locale` 与 `messages`：

```json
{
  "locale": "zh-CN",
  "messages": {
    "menu.home": "首页",
    "menu.customers": "客户管理"
  }
}
```

优先级：`options.locale/messages` > `bootstrap.locale/messages` > 浏览器语言 > `'zh-CN'`。

## DSL 中使用

页面 DSL 的文本属性支持 `${t('key')}` 表达式：

```yaml
body:
  type: Page
  props:
    title: ${t('page.customerList')}
  children:
    - type: Button
      props:
        text: ${t('action.save')}
```

注意：bootstrap 的**菜单标题不做表达式求值**（布局按字符串直渲染）。
菜单文案需多语言时，由服务端按用户语言下发，或在本地 bootstrap
工厂中自行查表。

## 参数插值

使用 `{{name}}` 占位符进行参数插值：

```yaml
props:
  message: ${t('welcome', { name: state.user.name })}
```

对应 messages：

```json
{
  "welcome": "Hello, {{name}}!"
}
```

## 回退机制

翻译回退顺序：当前 locale → defaultLocale → key 本身。

```tsx
createPactorApplication({
  appId: 'my-app',
  locale: 'fr-FR',           // 当前语言
  defaultLocale: 'zh-CN',    // 回退语言
  messages: {
    'zh-CN': { 'menu.home': '首页' },
    'en-US': { 'menu.home': 'Home' },
  },
});
```

当 `fr-FR` 缺失 `menu.home` 时，回退到 `zh-CN` 的 `'首页'`。

## 运行时切换语言

使用 `app.setLocale()` 在运行时切换语言：

```tsx
const app = createPactorApplication({ appId: 'my-app' });

// 切换为英文
app.setLocale('en-US');

// 切换并追加 messages
app.setLocale('en-US', {
  'menu.home': 'Home',
});
```

当前版本采用整页刷新策略：`setLocale` 调用后自动触发 `window.location.reload()`。

## 内置组件文案

Pactor 内置组件的默认文案使用稳定的 i18n key，可通过 messages 覆盖：

| key | 默认文案（zh-CN） | 说明 |
|-----|------------------|------|
| `pactor.table.loading` | 加载中… | Table 加载态 |
| `pactor.table.empty` | 暂无数据 | Table 空态 |
| `pactor.form.required` | 必填 | Form 必填校验提示 |
| `pactor.select.clear` | 清除 | Select 清除按钮 |
| `pactor.layout.expandSidebar` | 展开侧边栏 | 侧边栏展开按钮 |
| `pactor.layout.collapseSidebar` | 收起侧边栏 | 侧边栏收起按钮 |
| `pactor.layout.closeTab` | 关闭 {{title}} | 页签关闭按钮 |
| `pactor.layout.breadcrumb` | 面包屑 | 面包屑导航 |
| `pactor.datePicker.placeholder` | 选择日期 | DatePicker 单日期占位 |
| `pactor.datePicker.placeholderRange` | 选择日期范围 | DatePicker 范围模式占位 |
| `pactor.datePicker.today` | 今天 | DatePicker 内置预设「今天」 |
| `pactor.datePicker.thisWeek` | 本周 | DatePicker 内置预设「本周」（按 locale 计算周起始日） |
| `pactor.datePicker.thisMonth` | 本月 | DatePicker 内置预设「本月」 |

覆盖示例：

```tsx
createPactorApplication({
  appId: 'my-app',
  messages: {
    'pactor.table.empty': 'No data available',
    'pactor.form.required': 'This field is required',
  },
});
```

## 最佳实践

1. **仅对文案使用 `t()`**：逻辑判断仍用 `state` / `data` 表达式，避免 DSL 臃肿
2. **保持 key 扁平**：使用点路径命名空间（如 `menu.home`、`page.customerList`），避免深层嵌套
3. **服务端统一下发**：生产环境建议通过 bootstrap 下发 locale 与 messages，便于多语言管理
4. **覆盖内置 key 需谨慎**：内置 key 以 `pactor.` 开头，覆盖前请确认影响范围
