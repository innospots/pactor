
# 皮肤动态设置功能

- 用户可以通过加载一个css样式文件覆盖系统的页面样式，可以覆盖的样式及元素包括：
  页面背景（纯色、渐变、图片）、卡片阴影（颜色、大小）、按钮颜色（主色、副色、默认、警告、禁用等）、圆角大小、下拉菜单(hover、选中的背景颜色)
  Switch 的背景颜色及其滑块的颜色，Slider 的背景颜色、进度颜色、滑块颜色，Radio 前圆圈的默认及选中颜色，Progress 的背景及进度条颜色，Pagination 的当前页背景、边框、圆角的自定义，Menu 的 hover 及选中背景颜色，(Combobox | Command | Context Menu) 的 hover 及选中背景颜色，Chart 的颜色，Calendar 中的颜色

- 其它未提及的有背景颜色或 hover、active 颜色的组件
- 系统文字的字体及颜色
- 所有生成背景后的文字颜色也要考虑
