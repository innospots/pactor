# Spec: asset-library-pages

## Purpose

资产库的页面族：分类总览页、资产集合页（URL 可恢复的搜索筛选）、资产状态标识、资产详情页与通用异常状态。
## Requirements
### Requirement: 分类总览页

每个资产分类 SHALL 提供总览页，包含分类介绍、子菜单入口、精选资产、使用指引与关联分类导航。

#### Scenario: 打开分类总览

- **WHEN** 用户进入「组件总览」
- **THEN** 页面展示组件分类介绍、各二级分类入口卡片、精选组件与使用指引

### Requirement: 资产集合页

资产集合页 SHALL 包含标题与说明、搜索与筛选、排序、结果数量、资产卡片或表格、零结果状态、清除筛选操作与使用规则。搜索与筛选条件 MUST 写入 URL query，刷新、返回与分享链接后 MUST 恢复相同筛选状态。

#### Scenario: 筛选写入 URL

- **WHEN** 用户在 Token 表中按「类型=色彩、成熟度=稳定」筛选
- **THEN** 浏览器地址栏同步包含对应 query 参数，结果数量同步更新

#### Scenario: 从 URL 恢复筛选

- **WHEN** 用户打开带有筛选 query 的集合页链接
- **THEN** 页面水合后恢复对应筛选条件与过滤结果

#### Scenario: 零结果状态

- **WHEN** 筛选条件无任何匹配资产
- **THEN** 页面展示零结果状态与「清除筛选」操作，点击清除后恢复完整列表

### Requirement: 资产状态标识

资产状态 SHALL 使用相互独立的字段：成熟度（`稳定`/`实验`/`废弃`）、变更标识（`新增`/`更新`/无）、接入状态（`已接入`/`待资产接入`）、外链可用性（`可用`/`需复核`/`受限`/`失效`，仅外部资源）。成熟度与变更标识 MUST 显示在资产卡片上；接入状态 MUST 显示在数据字段或详情页；外链可用性 MUST 显示在外部资源卡片上；分类菜单 MUST NOT 显示这些标识。

#### Scenario: 卡片标识

- **WHEN** 用户浏览资产集合页
- **THEN** 每张卡片显示成熟度与变更标识（如有），不混入其他状态语义

#### Scenario: 外链卡片

- **WHEN** 用户浏览素材站点等外部资源卡片
- **THEN** 卡片显示外链可用性标识，失效条目禁用跳转并给出说明

### Requirement: 资产详情页

资产详情页 SHALL 包含资产预览、用途、成熟度、变更标识、接入状态、变体、使用规范、正反例、可复制参数或代码片段与关联资产。对某资产不适用的字段 MUST 显示「不适用」及原因，MUST NOT 静默省略。复制操作 MUST 给出成功或失败的明确反馈，复制内容 MUST 标注当前构建版本与 Git 提交号。

#### Scenario: 查看详情

- **WHEN** 用户打开一个资产详情页
- **THEN** 页面完整展示各规定章节，不适用章节标注「不适用」及原因

#### Scenario: 复制参数

- **WHEN** 用户点击「复制 CSS 变量」
- **THEN** 剪贴板获得对应内容，页面提示复制成功；剪贴板不可用或写入失败时提示复制失败

### Requirement: 通用异常状态

所有分类页面 MUST 处理页面加载失败、无资产、无搜索结果、资源缺失、引用断裂、复制失败与外链失效状态。废弃资产 MUST 保留详情入口并展示替代项链接；待接入资产 MUST NOT 展示模拟值冒充正式数据。

#### Scenario: 引用断裂

- **WHEN** 某资产的关联资产引用在构建数据中不存在
- **THEN** 构建期校验已阻断该情况；若线上因缓存出现，页面显示引用断裂提示而非空白或报错堆栈

#### Scenario: 废弃资产

- **WHEN** 用户打开一个废弃资产的详情
- **THEN** 页面显示废弃标识与替代资产入口

### Requirement: 模板分类内容接入与导航合成

「模板」分类的二级导航 SHALL 由硬编码骨架项与内容数据生成的菜单项合成。已接入内容的板块（线框模板）MUST 展示真实条目列表与详情页，未接入板块 MUST 保持「待接入」占位且不展示模拟内容。分类总览页的介绍与计数 MUST 如实反映已接入数量。

#### Scenario: 已接入板块展示真实内容

- **WHEN** 用户进入「模板 → 线框模板」
- **THEN** 页面展示真实模板条目列表，而非「待接入」占位

#### Scenario: 未接入板块保持占位

- **WHEN** 用户进入「模板 → 支付」
- **THEN** 页面仍展示「待资产接入」异常态与板块导航，不展示模拟条目

#### Scenario: 总览计数如实

- **WHEN** 用户进入「模板总览」
- **THEN** 「线框模板」板块卡片显示真实条目计数，未接入板块显示「待接入」徽章
