# Proposal: add-ui-asset-library

## Why

Pactor 已沉淀了完整的设计资产——样式 Token（@pactor-app/ui 语义令牌）、组件（packages/ui）、主题（theme-skin-css、design/themes.md）、模板与素材——但分散在源码、CSS 与设计文档中，设计师与研发没有统一的查找、理解与复用入口。`product-design/ui/` 下的六份设计文档（总体设计 + 样式/组件/主题/模板/素材）已定义了「UI 资产库」站点的完整信息架构与交互契约，本变更将其落地为可构建、可部署的站点。

## What Changes

- 在仓库根目录新建独立的 `doc/` 应用承载「资产库」站点（Astro，自定义三栏版式）；**不修改现有 `docs/` 文档站的任何内容**。
- 站点统一顶部导航：`文档｜资产库｜主题生成器｜案例`，其中主题生成器与案例标记为「待设计」，入口不指向不存在的页面。
- 资产库三栏框架：顶部导航（含搜索入口与构建版本）、左侧 240px 导航（一级分类 Tab：样式/组件/主题/模板/素材 + 二级子菜单，无三级）、中间内容区、右侧 280px 双态看板（默认目录与元信息，点击对象后切换为属性/说明看板）、底部构建信息栏（构建版本、最近同步时间、Git 提交号）。小屏幕左右栏收起为抽屉。
- 通用页面类型：
  - 分类总览页（分类介绍、子菜单入口、精选资产、使用指引、关联分类）；
  - 资产集合页（标题说明、搜索与筛选并写入 URL、排序、结果数量、卡片/表格、零结果与清除筛选、使用规则）；
  - 资产详情页（预览、用途、三轨状态字段、变体、使用规范、正反例、可复制参数/代码、关联资产；不适用字段显示「不适用」及原因）；
  - 通用异常状态（加载、无资产、无搜索结果、资源缺失、引用断裂、复制成功/失败、外链失效）。
- 资产数据层：Git 维护的结构化静态数据（构建期内嵌，不提供在线编辑/审核/权限/历史版本）；统一三轨状态字段（成熟度：稳定/实验/废弃；变更标识：新增/更新；接入状态：已接入/待资产接入；外链可用性仅用于外部资源）；稳定规范 ID 体系（token path / component_id / template_id / theme 与 family 前缀 / 素材 ID），跨文档引用经构建期校验。
- 首批完整交付「组件」与「主题」两个分类（真实数据，未接入部分标「待资产接入」、不展示模拟值）：
  - 组件：组件目录数据（137 个组件的验收矩阵清单），总览页（分类入口、覆盖矩阵、常用/最近更新）、分类集合页（搜索/筛选/排序、可交互卡片）、组件详情页骨架与代表性组件详情；
  - 主题：16 色系（family.*）入口与 80 主题数据契约（theme.* 前缀、OKLCH 色阶、modeSupport、差量/完整复制输出），色系集合页与主题详情页骨架；
- 「样式」「模板」「素材」三个分类本期仅提供导航入口与总览骨架，条目统一标注「待资产接入」，不填充模拟内容（数据契约与内容接入列为后续批次）。

## Capabilities

### New Capabilities

- `asset-library-shell`: 资产库站点框架——统一顶部导航、三栏响应式布局、分类 Tab 与二级子菜单、右侧双态看板、底部构建信息栏、全局搜索入口。
- `asset-library-pages`: 通用页面类型与交互——分类总览页、资产集合页（搜索/筛选写入 URL、排序、状态标识）、资产详情页（含复制操作与关联资产）、通用异常状态。
- `asset-library-data`: 资产数据模型与构建约束——稳定规范 ID、三轨状态字段、Git 静态内容管线、构建期引用校验与数量统计、复制内容的版本标注。

### Modified Capabilities

（无。现有 `docs/` 文档站不在本变更范围内，「文档」导航入口仅作为指向现有文档站的外链。）

## Impact

- **代码**：仓库根目录新增 `doc/` 应用（Astro）：资产库路由、布局组件、React 交互岛（筛选/复制/看板）、`src/assets-data/` 资产数据文件与构建期校验脚本；`docs/`、`packages/*` 均不改动。
- **依赖**：`doc/` 应用内新增 `astro`、`@astrojs/react`、`react`、`react-dom`、`wrangler`（dev）；加入 pnpm workspace。
- **部署**：`doc/` 为独立站点，自带 `wrangler.jsonc`，独立部署；构建期资产数据校验失败阻断构建。顶部导航的「文档」入口指向现有 docs 站地址。
- **文档**：design/DesignSystem.html 为版式与视觉基准；product-design/ui/ 六份文档为行为契约来源。
- **范围外（后续变更/批次）**：样式 Token 全量数据与 Token 表、模板与素材的内容接入（本期仅导航与总览骨架，标「待资产接入」）；主题生成器与案例模块的完整实现、在线编辑/审核/权限/历史版本（设计明确首期不做）。
